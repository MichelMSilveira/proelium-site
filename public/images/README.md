# Imagens do site Proelium

Esta pasta deve receber as imagens finais usadas no site institucional.

Sugestao de arquivos para a proxima etapa:

- `hero-home.jpg` - imagem principal da home, preferencialmente arquitetura/interior premium.
- `projeto-residencia.jpg` - projeto de automacao residencial.
- `projeto-cinema.jpg` - home cinema ou audio e video.
- `projeto-interiores.jpg` - ambiente integrado com automacao.
- `projeto-rack.jpg` - rack, cabeamento estruturado ou infraestrutura tecnica.
- `contact-project.jpg` - imagem de apoio para a chamada de contato.
- `og-image.jpg` - imagem de compartilhamento para redes sociais.

Recomendacoes:

- Usar imagens autorizadas.
- Evitar fotos com rostos, placas, documentos, senhas, telas internas ou dados de clientes.
- Preferir imagens horizontais em alta qualidade.
- Otimizar o tamanho antes de subir para o repositorio.
